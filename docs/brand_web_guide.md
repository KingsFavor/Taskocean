# TaskOcean 브랜드 웹 제작 지침서

> 이 문서는 TaskOcean 소개(마케팅) 웹사이트를 제작하기 위한 **단일 소스**다.
> 카피·색·타이포·기능 설명·스크린샷 배치·해서는 안 되는 주장까지 여기서 가져다 쓴다.
> 출처: `docs/PRD.md`, `CLAUDE.md`, `docs/design_reference.html`, `docs/dev_note.md`. 스크린샷: `docs/screenshots/{ko,en}/`.

---

## 0. 한 줄 정체성
**Google Tasks를 macOS 화면 위에 항상 떠 있는 작은 창으로 두고, 전역 단축키로 3초 안에 캡처하며, 여러 Google 계정을 하나의 화면에서 관리하는 경량 네이티브 유틸리티.**

웹의 모든 메시지는 이 네 축에서 벗어나지 않는다 → **항상-위 · 빠른 캡처 · 멀티 계정 · 하루 집중**.

---

## 1. 톤 & 보이스
앱 자체를 닮게: **조용하고, 저채도이며, 절제된 확신**.
- 느낌표·과장·"혁신적"·"최고의" 류 금지. 짧고 담백한 문장으로 실제 이점만.
- 시각도 여백과 저채도 팔레트 유지. 계정 색(블루/탄)은 점·아바타처럼 **소량 액센트로만**.
- 한국어 1차, 필요한 곳 영어 병기. 외래어 음차보다 우리말("하위 작업", "할 일").
- "방해하지 않는 상시 유틸리티"라는 성격을 카피와 디자인 양쪽에서 일관되게.

## 2. 헤드라인 후보 (히어로)
1. **할 일을 시야에서 놓치지 않게.** — Never let a task leave your sight.
2. **떠오르면 3초 안에. 어디서든 캡처.** — From thought to task in 3 seconds.
3. **업무와 개인, 하나의 작은 창에서.** — Work and personal, in one small window.
4. **오늘 하루에 집중하는 할 일 창.** — A to-do window built for today.
5. **항상 곁에, 조용히.** — Always beside you, quietly.

서브카피 예: "macOS 화면 위에 늘 떠 있는 작은 창. Google Tasks를 여러 계정까지 한눈에."

## 3. 핵심 가치 (섹션 4~5개로 전개)
| 이름 | 한 줄 | 대표 스크린샷 |
|---|---|---|
| **항상-위 (Always-on-top)** | 어떤 앱 위에서도 유지되는 작은 창으로 오늘 할 일이 늘 곁에 떠 있다. | `01-day-light` |
| **빠른 캡처 (Instant capture)** | 전역 단축키 한 번이면 다른 앱에서도 마우스 없이 3초 안에 저장. | (퀵캡처 — 아래 4.6 참고) |
| **멀티 계정 (Unified accounts)** | 업무·개인 등 여러 Google 계정을 계정 색으로 구분해 한 화면에서. | `07-filter`, `01-day-light` |
| **하루 집중 (One-day focus)** | 지남 → 오늘 → 날짜 없음. 넓은 기간은 히트맵으로 조망. | `09-heatmap` |
| **경량·조용함 (Lightweight & quiet)** | 상시 실행 네이티브 앱이지만 유휴 시 자원·시선을 최소화. | `04-mini` |

## 4. 기능 소개 (섹션/카드용)
각 기능에 대응 스크린샷을 표기했다. `{lang}` = `ko` 또는 `en`.

### 4.1 하루 뷰 — 제품의 얼굴
지남(Overdue) → 오늘 → 날짜 없음(Inbox) 순으로 유실 없이. 진행률 게이지, 완료 시 축하 애니메이션.
→ **`docs/screenshots/{lang}/01-day-light.png`**, 다크 **`02-day-dark.png`**

### 4.2 3가지 창 모드
미니(개수만 스트립) / 컴팩트(제목만) / 확장(상세). 필요에 따라 크기와 밀도를 바꾼다. 수동 리사이즈 + 모드별 크기 기억.
→ 확장 `01-day-light`, 컴팩트 **`03-compact.png`**, 미니 **`04-mini.png`**

### 4.3 멀티 계정 & 리스트 필터
여러 Google 계정을 통합 표시하고, 계정·리스트 단위로 표시를 켜고 끈다. 계정별 색/아바타로 구분.
→ **`07-filter.png`** (계정·리스트 토글 + 개수)

### 4.4 하위 작업 & 진행률
태스크당 1단계 하위 작업(인라인 추가/편집), 진행 게이지(예: 2/3).
→ **`06-subtasks.png`**

### 4.5 검색
제목·메모 전체 검색. 결과에 계정 아바타·리스트·날짜 표시.
→ **`08-search.png`**

### 4.6 빠른 캡처 (전역 단축키)
Spotlight 유사 창을 전역 단축키(기본 ⌥Space)로 띄워 어디서든 제목 입력 → Enter. 대상 계정/리스트 키보드 선택(⌘↑/⌘↓), 자연어 날짜 파싱("내일"·"금요일" / "tomorrow"·"Friday").
→ *별도 캡처 필요 시 요청*(현 세트 미포함). 대체로 하루 뷰 하단 "할 일 추가…" 인풋으로 대신 설명 가능.

### 4.7 히트맵 (넓은 기간 조망)
월 그리드 밀도로 어느 날 할 일이 몰렸는지 한눈에. 셀 클릭 시 그 날짜로 이동. **달력 뷰가 아니라 밀도 조망임**(§7 주의).
→ **`09-heatmap.png`**

### 4.8 부분 만료 격리 (재로그인 배너)
한 계정의 세션이 만료돼도 앱 전체가 멈추지 않는다. 그 계정만 비차단 배너로 재로그인 안내, 나머지 계정은 정상 동작.
→ **`05-reauth.png`** (개인 계정만 배너, 업무 계정은 그대로 동작)

### 4.9 그 외 (텍스트로만 나열해도 됨)
드래그 리오더 · 완료 태스크 일괄 정리 · 계정 간 이동 · 창 투명도 · 모든 스페이스 표시 · 자동 페이드 · Dock 배지 · 메뉴바 팝오버 · 로그인 시 자동 실행 · 로컬 알림 · 전역 단축키 재설정 · 한/영 현지화 · 완전 키보드 내비게이션 · VoiceOver.

### 5.5 히트맵 밀도(라이트)
빈 셀 `#EFEEEB` 위 잉크 오버레이 4단계: `rgba(20,20,19,.14)` → `.30` → `.50` → `.78`. 오늘 셀은 `#141413` 2px 링.
(웹에서 재현 시 계정 블루 `#5B7CA8`의 32% / 62% / 100% 오버레이로 대체 가능 — 앱 실제 구현과 일치.)

### 5.6 셰이프 토큰
- 창 라운드 **22** · 카드 **15** · 칩/뱃지 **7–9**
- 그림자는 은은하게: 예 `0 24px 56px -22px rgba(20,20,20,.34)`

### 5.7 타이포그래피
- 본문 스택: `"Pretendard Variable", Pretendard, -apple-system, system-ui, sans-serif`
- 로고 워드마크: **Playfair Display Italic 700**(세리프 이탤릭) + "TaskOcean" — 디자인 원본과 일치. (앱 내부는 시스템 세리프 이탤릭으로 근사)
- 모노(단축키 표기 ⌥Space 등): `ui-monospace, 'SF Mono', Menlo, monospace`
- 로고 자산: `Taskfish_logo.png` (물고기 마크). 워드마크 = 마크 + 텍스트 조합.

## 7. 포지셔닝 경계 — **주장/암시 금지** (PRD §3.2)
아래는 마케팅에서 절대 말하면 안 된다:
- **Windows / Linux / iOS 지원, "크로스플랫폼"** — macOS 전용.
- **자체 백엔드/동기화 서버, "우리 클라우드"** — 소스 오브 트루스는 Google Tasks.
- **팀 협업 / 공유 리스트 / 코멘트** — 협업 도구 아님.
- **간트·의존성·칸반 등 프로젝트 관리 고급 기능**.
- **달력 월/주 그리드 뷰** — 히트맵은 밀도 조망이지 캘린더가 아니다. "캘린더" 기능처럼 광고 금지.
- **별도 "마감일(deadline)" 관리** — 공개 API의 `due`는 시간 없는 **날짜(예정일)**만. 별개 deadline 필드 없음. 시간 알림은 로컬 알림으로만 보완.

## 8. 플랫폼/사실 (푸터·스펙 섹션)
- **플랫폼:** macOS 전용, 최소 **macOS 14 Sonoma**, Apple Silicon/Intel 유니버설.
- **기술:** 네이티브 Swift/SwiftUI + AppKit (Electron 아님).
- **연동:** Google Tasks API 동기화(폴링), 여러 Google 계정(Workspace + 개인).
- **보안:** OAuth 2.0 PKCE + 커스텀 URL 스킴, 토큰은 macOS Keychain, App Sandbox 호환, 최소 권한.
- **배포:** TestFlight / Mac App Store 우선.
- **번들 ID:** `com.dws.taskocean` · 제작 DWS(KR).
- **상태:** 현재 실백엔드 연동 완료·검증 단계. 웹에는 "곧 출시" / TestFlight 대기 형태의 CTA 권장(정식 출시일·가격 미확정이므로 단정 금지).

## 9. 권장 페이지 구성 (단일 랜딩)
1. **히어로** — 워드마크 + 헤드라인(§2) + 서브카피 + `01-day-light` 목업 + CTA("출시 알림 받기" 등).
2. **핵심 가치 3~5** — §3 표를 카드로. 각 카드에 대표 스크린샷.
3. **3가지 창 모드** — `04-mini` / `03-compact` / `01` 나란히.
4. **멀티 계정** — `07-filter` + 계정 격리(`05-reauth`) 스토리.
5. **하루 집중 + 히트맵** — `09-heatmap`.
6. **디테일 그리드** — 하위작업/검색/드래그/단축키 등 작은 아이콘+한 줄.
7. **다크 모드** — `02-day-dark` (라이트/다크 토글 데모면 더 좋음).
8. **스펙/푸터** — §8 사실 + 비목표에 안 걸리는 문구.

## 10. 기술 권장
- 정적 사이트(빠르고 가벼움 — 제품 성격과 일치). 자체 호스팅 폰트 또는 Pretendard CDN.
- **반응형** 필수(모바일에서 창 목업은 세로 스택). **다크 모드** 대응(`prefers-color-scheme`, 팔레트 §5.3/5.4).
- 접근성: 충분한 대비, 이미지 alt(스크린샷 설명), 키보드 포커스.
- 다국어: 한국어 기본 + 영어. 이미지도 언어별(ko/en) 세트 사용.
- 성능: 스크린샷은 레티나 2x 원본을 적절히 리사이즈/`srcset`.
